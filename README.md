> **「サイゼの注文を極めし者へ」**  
> 表示されるサイゼリヤの人気メニュー名を見て、4桁の注文コードを瞬時に入力するスピードタイピングゲームです！

---

## 🎮 概要

サイゼリヤで注文用紙に記入するあの**「4桁の注文番号」**を、どれだけ素早く正確に入力できるかを競うファンメイドのブラウザゲームです。  
外部ライブラリを一切使わないピュアな HTML / CSS / Vanilla JavaScript で実装されており、PCのキーボードはもちろん、スマートフォンやタブレットのタッチ入力（バーチャルテンキー）にも完全対応しています。

---

## ✨ 主な機能 & 特徴

- 🍕 **充実のメニューデータベース（80品以上収録）**  
  ミラノ風ドリア(`2101`)、辛味チキン(`1401`)、小エビのサラダ(`1202`)などの定番から、ワインやデザートまで網羅！
- ⏱️ **選べる3つのゲームモード**
  - **タイムアタック**: 10問正解するまでのスピードを計測。正確性と瞬発力がカギ！
  - **サバイバル**: 持ち時間30秒からスタート。正解で+3秒、ミス/時間切れで-5秒。限界まで生き残れ！
  - **練習モード**: 制限時間なし・問題数無制限。ヒントを見ながらマイペースにメニューを覚えられます。
- 🏷️ **メニューカテゴリの絞り込み**  
  全メニュー、前菜・おつまみ、サラダ・スープ、パスタ・ピザ、ドリア・肉料理、デザート、ドリンク・お酒から自由に選択可能。
- 🧾 **サイゼリヤ伝票風リザルト画面**  
  ゲーム終了時には、正解したメニューが並ぶリアルなレシートが生成され、想定合計金額や注文分析（得意メニュー・苦手メニュー）を表示。
- 🏅 **称号判定システム**  
  タイムや正解数、入力精度に応じて「初来店」「一般客」「サイゼ通」「サイゼ魔人」「サイゼ神」の称号が授与されます。
- 🔊 **Web Audio API によるダイナミック効果音**  
  正解チャイム（コンボ数に応じて音程が上昇！）、ミス音、歓声・ファンファーレ、BGM/SEのミュート切り替えに対応。
- 📱 **レスポンシブ & 仮想テンキー**  
  PC物理キーボードの数字入力・テンキー入力に加えて、画面内のタッチ対応バーチャルキーパッドを搭載。

## 🕹️ 操作方法

### PCキーボード
| キー | 操作内容 |
| :--- | :--- |
| **`0` 〜 `9`** (数字キー / テンキー) | 4桁の注文コードを入力 |
| **`Backspace`** | 1文字消去 |
| **`Esc`** または **`Delete`** | 入力中のコードを全消去（クリア） |
| **`Space`** | スキップ（パス） |

### 画面上ボタン（マウス / スマホ操作）
- **バーチャルキーパッド (`0`〜`9`)**: 画面上のボタンを直接クリック・タップして入力
- **`⌫`**: 1文字削除
- **`CLR`**: 入力中コードを全消去
- **ヒントを見る**: コードの上2桁（練習モードでは全桁）を表示
- **パス**: 現在の問題をパスして次のメニューへ

## 🚀 遊び方 / 起動方法

### ローカルで直接開く場合
ビルドやインストールの手順は不要です。

1. 本リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/your-username/saizeriya-code-game.git
   ```
2. フォルダ内の `index.html` を任意のブラウザ（Google Chrome, Edge, Safari, Firefoxなど）でダブルクリックして開きます。

### ローカルサーバーを使用する場合（推奨）
VS Codeの「Live Server」拡張機能や、Python等のシンプルなHTTPサーバーでも手軽に起動できます。

```bash
# Python 3 の場合
python -m http.server 8000

# Node.js (npx serve) の場合
npx serve .
```
起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
